# Rádio Tatuapé FM Slots 🎰

Bem-vindo ao projeto **Rádio Tatuapé FM Slots**, um jogo de caça-níquel online divertido e envolvente! 🚀

## 🎯 Funcionalidades Principais
- **Saldo Inicial**: Gerencie seu saldo para apostas.
- **Valores de Aposta**: Escolha entre diferentes opções de aposta: R$ 2, R$ 5, R$ 10, R$ 20 e R$ 50.
- **Ações Disponíveis**:
  - Girar a máquina de caça-níquel.
  - Adicionar saldo à sua conta.
  - Solicitar retirada dos seus ganhos.
  - Verificar prêmios conquistados.
- Desenvolvido com paixão por **Julio Campos Machado**.

## 💻 Tecnologias Utilizadas
- **Frontend**: React.js
- **Backend**: Node.js
- **Hospedagem**: Vercel

## 📜 Instalação e Uso
Siga as etapas abaixo para clonar e executar o projeto localmente:

1. Clone o repositório:
   ```bash
   git clone https://github.com/seu-usuario/radio-tatuape-fm-slots.git
   ```
2. Navegue até o diretório do projeto:
   ```bash
   cd radio-tatuape-fm-slots
   ```
3. Instale as dependências:
   ```bash
   npm install
   ```
4. Inicie o servidor:
   ```bash
   npm start
   ```
